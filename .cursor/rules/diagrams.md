# Diagrams or Charts
- When explain a process or logic use a mermaid diagrams.

# ER Diagram
- Search in project if contains migrations to scan them and create an ER Diagram.

# Sequence diagram
- Use specific actors and separate complete features in a single diagram.

# Components diagram
- Scan all files and directories to structure components.
- Everytime create 3 components diagrams.
  - first one a high components diagram (like a high level).
  - second one a medium leve components with proposes, opportunities to scale and improve.
  - last one a detailed diagram about each component and the possibility to improve and scale.
